# PICO Community Code of Conduct

PICO welcomes people who want to learn, build, review, document, and improve the project. Participation in the repository's issues, pull requests, code reviews, and other project spaces is expected to be respectful and constructive.

## Expected Behavior

- Treat people with respect, patience, and consideration.
- Discuss technical disagreements in good faith and focus criticism on ideas or code, not individuals.
- Welcome questions and contributions from people with different experience levels and backgrounds.
- Give actionable feedback and accept corrections gracefully.
- Respect privacy. Do not publish another person's personal information, credentials, private conversations, logs, or household data.
- Keep discussions relevant, collaborative, and focused on improving the project.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, threats, intimidation, or sustained personal attacks.
- Doxxing or sharing private or identifying information without consent.
- Publishing passwords, tokens, API keys, private conversations, security reports, or other confidential material.
- Unwelcome sexual attention or sexualized content in project spaces.
- Deliberate disruption, spam, or repeated bad-faith conduct.
- Encouraging unsafe use of PICO against systems, accounts, devices, or people without authorization.

## Maintainer Responsibilities and Enforcement

Project maintainers are responsible for clarifying and enforcing this code. They may edit or remove content, close discussions, restrict participation, or remove a contributor from project spaces when behavior is harmful or disruptive. The response will depend on the severity and context of the conduct.

Maintainers should explain enforcement decisions where doing so is safe and practical. This code does not create a guaranteed response time or appeal process.

## Reporting a Concern

For conduct concerns, contact the repository owner privately through the contact method available on the [Lurkaee GitHub profile](https://github.com/Lurkaee). Do not post personal information or sensitive details in a public issue.

For security vulnerabilities, use the private reporting guidance in [SECURITY.md](SECURITY.md).

## Scope

This code applies in PICO repository spaces and when someone is publicly representing the project or its community. It also applies when project participation materially affects the safety or well-being of another participant.
